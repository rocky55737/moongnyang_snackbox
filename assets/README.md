# assets

선택적으로 넣어 비주얼/사운드를 업그레이드할 수 있는 폴더입니다. 비어 있어도 게임은 정상 동작합니다.

- `font.ttf` — 한글 폰트를 직접 넣으면 라벨에 우선 사용됩니다.
  (없으면 시스템에 설치된 한글 폰트를 자동 탐색합니다.)
- `merge.wav` — 간식이 합쳐질 때 재생되는 효과음.
- `bugi.wav` — 부기 완성/펑 효과음.

> 추후 단계별 스프라이트(`tier_0.png` ...)를 쓰고 싶다면
> `src/ui/renderer.py`의 `draw_snack`에서 이미지 로딩 분기를 추가하면 됩니다.
